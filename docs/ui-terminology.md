# Shared select terminology

| Message ID | Meaning | Vietnamese |
| --- | --- | --- |
| `common.actions.retry` | Retry a failed initial or next-page select request | Thử lại |
| `common.actions.loadMore` | Explicit keyboard-accessible next-page action | Tải thêm |
| `common.select.loadingMore` | Next select page is in flight | Đang tải thêm |
| `common.select.loadError` | Select data load failed, separate from an empty result | Không thể tải dữ liệu |
| `common.select.minSearch` | Minimum search length, with `{count}` | Nhập ít nhất {count} ký tự để tìm kiếm |

Reuse these IDs in Vietnamese/English catalogs. Dynamic material names and user-authored content remain outside the catalogs.
